# Changes On 2026-05-08

This page records the structural and test changes made during the May 8, 2026 implementation session.

## Schema Package

Added `satoidc/satoidc/schemas/` as the central package for Pydantic request/form schemas.

Current modules:

- `schemas/lnurl.py`: `LnurlAction`, `LnurlAuthCallbackIn`.
- `schemas/login.py`: `LoginSchema`, `LoginForm`.
- `schemas/register.py`: `RegisterSchema`, `RegisterForm`.
- `schemas/__init__.py`: public re-exports for the schema package.

The old `satoidc/satoidc/auth/lnurl_schemas.py` compatibility shim re-exported
LNURL schemas from `satoidc.schemas.lnurl` until it was removed after import
usage was validated.

## Registration Flow

`satoidc/satoidc/routes/register.py` now separates UI rendering from registration behavior.

Behavior added:

- `POST /register` validates the submitted form server-side.
- The endpoint requires terms acceptance.
- The endpoint validates login, nickname, password and email with the existing validators.
- Password confirmation is checked before persistence.
- Duplicate login or email is rejected before insert.
- `redirect_to` is sanitized with `safe_redirect`.
- Successful registration creates the user, hashes the password, stores `request.session["user_id"]`, and redirects the already-authenticated user.

The NiceGUI `/register` page now renders a standard HTML form that posts to `/register`, keeping visual concerns in the page and persistence/session behavior in the endpoint.

The flow is documented in `specs/flows/registration.md` and linked from `specs/flows/README.md` and `specs/index.md`.

## Bug Fix

Fixed `satoidc/satoidc/fastapi_oauth2/authorization_server.py` metadata loading.

The code previously used `json.loads(metadata_file_content)` on an open file object. It now uses `json.load(metadata_file_content)`, which is the correct parser for file handles.

Lines excluded from unit coverage are intentionally limited to code that is better covered by browser smoke tests or is purely compatibility/defensive glue:

- NiceGUI page-rendering functions and visual helper functions.

- The compatibility re-export module `auth/lnurl_schemas.py` was later removed

## Page Security

`page_security` is now treated as authorization logic and is covered by focused tests.

Changes:

- Extracted active permission loading into `get_active_user_permissions`.
- Extracted request authorization into `authorize_page_request`.
- `page_security` now delegates to those helpers and returns the protected page result.
- Invalid UUID session values redirect to `/login` instead of raising.
- Removed diagnostic `print` output from the authorization path.
- Permission comparison now normalizes `PermissionsEnum` and string values before checking `root`, `all`, and `any` modes.

Tests cover:

- active permission filtering.
- disabled and expired permission exclusion.
- missing session redirect.
- invalid UUID session redirect.
- forbidden redirect for missing permissions.
- successful root authorization.
- decorator pass-through and redirect behavior.
