# Flows

Use this folder for reusable flow descriptions that multiple feature specs can reference.

Good candidates in SatOIDC:

- OIDC authorization code flow.
- Login and registration flows.
- LNURL-auth challenge and callback flow.
- Client registration and dashboard flows.
- Logout and session handling.

Keep flows observable and step-based. Link to contracts when request/response shape matters.
